# Задачи

Одна цель — одна продолжаемая карточка с требованиями, фактами, решением, проверками, ограничениями и следующим шагом. Новую карточку назовите `YYYY-MM-DD-короткая-тема.md` и зарегистрируйте в [состоянии](../STATUS.md). [Образец](TEMPLATE.md) не является активной задачей.

Не переносите сюда личные поручения владельца, переписки и подробности закрытых установок. Завершённая карточка переносится в [архив](../archive/README.md), ссылки обновляются. Сейчас активных карточек разработки нет.
