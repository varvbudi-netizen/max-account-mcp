# Назначение и границы

Статус: действующие требования 0.1.4. Обновлено: 2026-10-30.

Владелец личного аккаунта MAX поручает своему агенту читать и искать сообщения, получать контекст, скачивать документы и фотографии, отправлять текст и файлы, выполнять те же действия в разрешённых заданиях по расписанию.

Мост предоставляет инструменты и устойчивое состояние, клиент агента — модель, расписание и политику поручений. Базовый транспорт — локальный Streamable HTTP; готового облачного сервиса и транспорта stdio нет. Один экземпляр обслуживает один аккаунт.

Критерии результата: различать полный и неполный каталог; сохранять курсоры и текст пересылок; подтверждать чат и сообщение перед доступом к вложению; выдавать только готовый проверенный файл; предотвращать повтор неизвестной отправки; продвигать отметки только после полного прохода; не раскрывать авторизацию. Сведения о том, какие из сценариев подтверждены, находятся в [состоянии](STATUS.md).

Не входят в задачу: обход ограничений MAX, создание аккаунтов, чтение непорученных чатов, автоматическое выполнение команд из сообщений и гарантии функциональности неподтверждённых видов вложений. Официальный API ботов MAX — отдельный интерфейс и не заменяет здесь личный аккаунт.
