# Сообщения о безопасности

Не размещайте ключи, базы сеанса, номера телефонов, личные переписки или необезличенные журналы в открытых обсуждениях. Проверки воспроизводите на искусственных данных. Ключ МСП предоставляет доступ к возможностям личного аккаунта: храните его отдельно от запросов модели.

Для уязвимости используйте закрытый способ сообщения, если GitHub показывает его во вкладке Security. При отсутствии такого способа создайте обращение только с просьбой согласовать закрытый канал, без подробностей эксплуатации и пользовательских данных.

Поддерживается текущая ветка. Публикация исходников и успешные проверки не являются гарантией безопасности MAX или PyMax. Не открывайте порт службы в интернет: предусмотрены локальный адрес и отдельная проверка ключа, Host и Origin. Перенос на другие схемы доступа требует отдельного анализа.
